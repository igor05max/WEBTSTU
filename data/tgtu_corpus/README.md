# Корпус статей ТГТУ, 2022–2026

Источник: [папка Google Drive «Статьи ТГТУ 2022–2026»](https://drive.google.com/drive/folders/1eyWc5oeaRviEpVct1spsbfrtgXERwjNo).

`manifest.jsonl` содержит метаданные 545 PDF из двух журналов. Это перечень
файлов, а не сами PDF. Поле `decision` содержит 542 кандидата (`candidate`)
и 3 исключения (`exclude`): два памятных материала и одну копию статьи с
повторяющимся DOI. Кандидат ещё не означает пригодность для цитирования.
Перед выдачей источника нужны проверка ссылки и сопоставление её с конкретной
статьёй. Исключённые записи сохранены, чтобы решение можно было проверить.

Манифест фиксирует путь PDF внутри распакованной папки Drive, SHA-256 из
исходного JSON, DOI, страницы, ссылки издателя и идентификатор исходного JSON.
Хеши PDF ещё требуется сверить с фактическими байтами при загрузке. Полный
текст и качество его извлечения также пока не проверены для всех 545 файлов.
Поле `link_verification` хранит результат последнего сетевого аудита;
подробности и HTTP-ответы находятся в `link_audit.jsonl`. Только поле
`verified_source_url` предназначено для автоматической выдачи источника.
`legacy_fallback_url` содержит дополнительную карточку eLIBRARY, у которой
подтверждена связь со статьёй, но открытие без входа на сайт не подтверждено.
Не следует автоматически выдавать сломанный DOI или считать сетевой тайм-аут
доказательством отсутствия статьи.

Для 161 статьи «Вестника» 2023–2025 к манифесту добавлены адреса eLIBRARY из
прежнего каталога RAG. Совпадение проверено по DOI, году и страницам (153
заголовка совпадают после нормализации, у 8 есть перевод или вариант записи).
SHA-256 всех 161 старых PDF совпал с манифестом, и ожидаемый DOI найден на
первой странице каждого файла (`legacy_pdf_checks.jsonl`). Поле
`legacy_link_verification: unverified` означает, что саму страницу eLIBRARY
открыть и подтвердить из текущей сети пока не удалось.
Файл `legacy_abstracts.jsonl` содержит 320 русских и английских аннотаций
этих статей из прежнего поискового индекса. Они помогают найти статью при
различии языков запроса и PDF; в интерфейсе явно отмечаются как аннотации
карточки eLIBRARY.

Сетевой аудит 2026-10-04: DOI 330 статей отвечают HTTP 404 и отсутствуют
в выборке Crossref; у 52 записей подтверждён конкретный URL издателя или
работающий DOI, у 161 есть подтверждённая по PDF запасная карточка eLIBRARY.
В оставшихся случаях ссылка на статью требует повторной проверки или
исправления. Статус `broken` в манифесте означает, что указанный DOI сломан
и подтверждённой альтернативы пока нет; он не означает отсутствия самой
публикации. Эти данные зависят от доступности сайтов на момент запуска.

Повторить объединение старого каталога с манифестом:

```powershell
python scripts/merge_legacy_citation_links.py --legacy-csv downloads_elibrary/journal_articles_full_metadata.csv
```

Повторить проверку публичных ссылок (требуется доступ к Crossref и сайтам
издателей):

```powershell
python scripts/audit_tgtu_links.py
```

Проверить старые PDF и применить результаты к манифесту:

```powershell
python scripts/verify_legacy_pdf_identity.py --pdf-root downloads_elibrary
python scripts/apply_tgtu_link_audit.py
python scripts/export_legacy_abstracts.py --legacy-index tmp/citation_index.sqlite3
```

Годовые ZIP повторяют содержимое распакованных папок и не должны попадать в
индекс как отдельные публикации. Рабочий сайт продолжает использовать прежний
корпус eLibrary; этот манифест сам по себе не меняет поиск.
