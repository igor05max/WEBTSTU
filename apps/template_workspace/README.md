# Оформление статьи по шаблону

Личный кабинет `/template/`: загрузка статьи и шаблона (DOCX/PDF/TEX/ZIP),
постоянная история сборок, структурный план, предпросмотр PDF, скачивание
LaTeX ZIP, главного TEX и JSON-отчёта. Файлы доступны только владельцу.

Первый этап `ConversionPipeline` извлекает `ArticleIR` и `TemplateProfile`,
затем создаёт LaTeX-проект. Второй этап `LatexCompiler` компилирует именно этот
проект. DOCX-генератор в этом рабочем пространстве не используется.

Загрузка создаёт `TemplateJob`, затем после фиксации транзакции запускается
`python manage.py run_template_job UUID`. Страница опрашивает статус каждые
4 секунды. Готовые результаты хранятся в `MEDIA_ROOT/template_workspace/UUID/`.
Скачивание не запускает генерацию. Одновременно допускается одна активная
сборка на пользователя. Если процесс прервался, сборка отмечается как неудачная
после 20 минут при следующем обращении к странице. На Linux действует лимит
времени рабочего процесса 18 минут. Ошибки записываются в Django logger
`apps.template_workspace.services`.

Для production установите `texlive-xetex` вместе с зависимостями из
`deploy/README.md`, выполните миграции и перезапустите `webtstu`.
Qwen использует существующие настройки `AI_BASE_URL` и `AI_MODEL`.
При отсутствии настройки модели применяется локальная классификация.
Если компилятор не смог собрать PDF, сохраняются LaTeX и отчёт, интерфейс
показывает необходимость проверки, а не успешную сборку.

Проверка: `python manage.py test apps.template_workspace`.
